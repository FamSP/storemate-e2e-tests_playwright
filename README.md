# StoreMate E2E Tests (Playwright)

ชุดทดสอบอัตโนมัติของระบบ StoreMate ส่วนดูและค้นหาสินค้า (ไม่ต้องเข้าสู่ระบบ) ตามเอกสาร **StoreMate-Test-Cases.docx** ฉบับ 3.0
รวม **38 Test Case ใน 3 User Story** ชื่อเทสขึ้นต้นด้วยรหัส เช่น `TC-03-01 (TC5001) แสดงรายการสินค้า` (ในวงเล็บคือรหัสเดิมจากเอกสาร ถ้ามี)

## ติดตั้ง

ต้องมี Node.js 18 ขึ้นไป

```bash
npm install
npx playwright install chromium
copy .env.example .env
```

ไม่ต้องใช้บัญชีผู้ใช้ ค่าใน `.env` มีแค่ `BASE_URL` และ `PRODUCT_ID`

## รันเทส

| คำสั่ง | ทำอะไร |
|---|---|
| `npm test` | รันทั้งหมด (38 เทส) |
| `npx playwright test tests/guest/04-search.spec.js` | รันทีละไฟล์ |
| `npx playwright test -g "TC-04-09"` | รันเทสเดียวตามรหัส |
| `npm run test:headed` | รันแบบเห็นหน้าจอเบราว์เซอร์ |
| `npm run test:ui` | เปิด UI mode เลือกรันทีละเทส |
| `npm run report` | เปิดรายงาน HTML หลังรันเสร็จ |

ถ้าเทสไม่ผ่าน จะมีภาพหน้าจอ วิดีโอ และ trace อยู่ใน `test-results/` (เปิด trace ด้วย `npx playwright show-trace <ไฟล์ trace.zip>`)

## ข้อควรรู้

- **เทสเขียนกับเว็บจริง** ตัวเลือก (selector) มาจาก `data-test` ในโค้ด storemate และข้อความแจ้งเตือนคัดลอกจากโค้ดตรงตัว
- **เทสอ่านอย่างเดียว** ไม่สร้างบัญชี ไม่ใส่รถเข็น ไม่สั่งซื้อ จึงรันซ้ำได้ไม่กระทบข้อมูล
- **สินค้าที่ใช้ต้องพร้อมขาย:** ณ 11/10/2569 สินค้า 28 และ 30 สต็อกหมด จึงใช้ 53 เป็นค่าเริ่มต้น
- **เทสที่จะถูกข้าม (skipped) ถ้าข้อมูลไม่พร้อม:**
  - TC-03-02 ถ้าทุกหมวดมีสินค้า
  - เทสสินค้าสต็อกหมด ถ้าตอนนั้นไม่มีสินค้าที่สต็อกหมด
  - เทสเพิ่ม/ลดจำนวนในหน้ารายละเอียด ถ้าสต็อกน้อยกว่า 3 ชิ้น
